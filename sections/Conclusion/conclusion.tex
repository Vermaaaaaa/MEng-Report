\subsubsection{Model Hyperparameters}
The main thing to do is to determine the models' hyperparameters such as, the kernel
size, receptive field, dilation factor. 

Ultimately, the receptive field size is determined by the dilation factor and the kernel size. 
To this end, the receptive field will be changed based on the performance of the model. To start
with an arbitrary value of two seconds will be chosen to see how the model performs. If by increasing
the size of the receptive field, the model performs better this will be done. However, it's 
important to note that further increasing the receptive field will be computationally expensive
and may not increase performance. As such a cutoff point will be defined during testing, that
balances the performance to computation time to ensure that the model has some real-time
capability.  

For dilation factor, it is a common method to follow is $d = 2^i$ or $d = 4^i$ where $i$, 
is the layer number as seen by \cite{brossard_2020_denoising}. This is because by increasing
the dilation factor the model can see further back in time and use this information to predict the accumulation of errors more accurately. However, as this is not a standard rule a wide
variety of dilation factors will be used to test model performance. 

The next thing to consider, is the kernel size $k$. This will be kept constant throughout the 
model to ensure that the receptive field does not grow too much past the cutoff point. To determine
all of these factors we can use the equation below

\begin{equation}
    R = max(kernel size * dilation factor)
\end{equation}

so if we have four layers, our dilation factor will be $d = 64$ from $d = 4^i$, and 
a kernel size of $k = 8$, then our receptive field will be $R = 512$ multiplied with
our sample period $\Delta t = \frac{1}{286}$, results in a history of $1.8s$.
