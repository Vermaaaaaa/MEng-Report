\subsection{Research Question and Hypotheses}
\label{sec:question}
The question this project aims to answer is: \textbf{"Can Deep Learning be used to learn the drift 
pattern to get drift reduced orientation estimation?"} While this is the overarching question, it can be 
broken down to the following:
\begin{itemize}
  \item How effectively can deep learning learn the drift experienced?
  \item Can this model generalise to unseen conditions?
  \item What are the advantages or disadvantages of using Deep Learning compared to traditional
    approaches? 
\end{itemize}

The hypothesis that I state for this project is that by incorporating a deep-learning 
model, we will be able to see a percentage decrease in the orientation error
over a period of time.
